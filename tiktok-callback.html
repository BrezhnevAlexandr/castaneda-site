Waiting for the authorization response…

This page is the redirect target of our TikTok Login Kit integration. TikTok sends the one-time authorization code here; the code is then exchanged for an access token by our publishing service. The exchange needs the app's client secret, so it never happens in the browser — this page only confirms that the authorization step completed.
