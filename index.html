Castaneda Quotes

Automated short-video project — quotes from Carlos Castaneda's books, turned into short vertical videos and published to social platforms.

What this is

This is a personal automation project. It selects quotes from Carlos Castaneda's published books, generates short cinematic videos with narration and subtitles, and publishes them to platforms such as YouTube and TikTok via their official APIs.

How it uses platform APIs

  • TikTok Content Posting API / Login Kit — to publish the project's own generated videos to the project owner's TikTok account.
  • YouTube Data API — to upload the same videos to the owner's YouTube channel.

The app acts only on the account of its owner. It does not collect data from other TikTok users or viewers.
